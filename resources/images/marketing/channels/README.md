Official channel icons go here (asset slot). File name = channel id:

- avito.svg (or .png / .webp)
- telegram.svg
- max.svg
- site.svg

They are picked up automatically by `resources/js/marketing/components/ChannelIcon/ChannelIcon.tsx`.
Until a file exists, a neutral icon is shown. Do not draw brand logos yourself: use the official assets only.
